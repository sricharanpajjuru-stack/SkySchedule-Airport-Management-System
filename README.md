# ✈️ SkySchedule: Airport Management System

SkySchedule is an airport management system that helps manage flight schedules, gates, passengers, and airport operations in one place, making day-to-day coordination faster and more organized.

## 🔗 Live Demo

https://sricharanpajjuru-stack.github.io/SkySchedule-Airport-Management-System/

*(Works once GitHub Pages is enabled and the main file is named `index.html`.)*

## ✨ Features

- Flight scheduling and tracking
- Gate and runway allocation
- Passenger and booking records
- Simple, easy-to-use interface

## 🛠️ Built With

- HTML
- CSS
- JavaScript

## 🚀 How to Run

1. Download or clone this repository:
   ```bash
   git clone https://github.com/sricharanpajjuru-stack/SkySchedule-Airport-Management-System.git
   ```
2. Open the project folder.
3. Double-click `index.html` to open it in your browser.
